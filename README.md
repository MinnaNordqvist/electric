# Electricity app
Solita Academy Exercise

## How to use:
### Prerequisites
- Docker Desktop (running)
- Node.js 
### Installation and Setup:
1. Clone the repository  

```
git clone https://github.com/MinnaNordqvist/electric
cd electric
```

2. Start Database and Docker
`docker compose up -d --build`
